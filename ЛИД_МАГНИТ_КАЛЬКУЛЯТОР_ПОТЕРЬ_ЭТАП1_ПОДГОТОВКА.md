## 📋 ЭТАП 1: ПОДГОТОВКА

### 1.1 Цель лид-магнита

**Главная цель:**
Показать владельцу Instagram-магазина **ОГРОМНЫЕ потери** из-за необработанных заявок и создать срочность решения проблемы.

**Микропроблема, которую решаем:**
> "Сколько денег я теряю каждый день из-за того, что не успеваю обрабатывать все заявки в Instagram?"

**Что НЕ делаем (не крадем ценность главного продукта):**
- ❌ НЕ показываем КАК автоматизировать
- ❌ НЕ даем техническую инструкцию
- ❌ НЕ раскрываем методологию ICRM Framework

**Что делаем:**
- ✅ Показываем ЦИФРУ потерь (ВАУ-эффект)
- ✅ Создаем осознание проблемы
- ✅ Ведем на диагностическую сессию логично

**Ожидаемый результат:**
Клиент за 2-3 минуты узнает точную цифру потерь в день/месяц/год и понимает: "Охренеть, я теряю 2,625,000₽/мес! Нужно срочно что-то делать!"

---

### 1.2 Ракурс (как подаем)

**Эмоциональный триггер:** СТРАХ УПУСТИТЬ (FOMO) + ШОК от цифры

**Тон общения:**
- Прямой, без воды
- "Говяжий язык" (просто и понятно)
- Не запугиваем, а показываем факты
- Дружеский, но серьезный

**Ключевое сообщение:**
> "Каждая необработанная заявка в Instagram = упущенные деньги. Посчитайте, сколько вы теряете прямо сейчас."

### 1.3 Формат

**Технический формат:**
- HTML форма с JavaScript калькулятором (iframe для Tilda)
- Поля для ввода:
  - Средний чек (₽)
  - Заявок в день (штук)
  - Обрабатываете (%)
- Автоматический расчет при вводе (без кнопки "Рассчитать")

- Калькулятор только показывает цифры
- CTA "Хочу исправить" / "Запишитесь на консультацию" — в Tilda вне iframe

**Структура лендинга на Tilda:**
```
1. Заголовок (в Tilda)
2. Подзаголовок (в Tilda)
3. Калькулятор (HTML iframe)
4. Интерпретация результата (в Tilda, под калькулятором)
5. CTA кнопка (в Tilda) → Telegram-бот
```

## 📐 ЭТАП 2: СКЕЛЕТ (СТРУКТУРА)

### 2.1 Формулы расчета

**Базовая формула:**

```
ПОТЕРИ В ДЕНЬ = Заявок в день × (100% - Обработано%) × Конверсия × Средний чек
```

**Где:**
- **Заявок в день** — вводит клиент
- **Обработано%** — вводит клиент (например, 25% если обрабатывает 50 из 200)
- **Конверсия** — 20% (средняя конверсия при быстрой обработке, фиксированная)
- **Средний чек** — вводит клиент

**Дополнительные расчеты:**
- **Потери в месяц** = Потери в день × 30
- **Потери в год** = Потери в месяц × 12
- **Необработанные заявки в день** = Заявок в день × (100% - Обработано%)

**Пример расчета:**
- Заявок: 200/день
- Обрабатываете: 25% (50 заявок)
- Средний чек: 3,500₽
- Конверсия: 20%

```
Необработанные заявки = 200 × 75% = 150 заявок/день
Потери в день = 150 × 20% × 3,500₽ = 105,000₽/день
Потери в месяц = 105,000₽ × 30 = 3,150,000₽/мес
Потери в год = 3,150,000₽ × 12 = 37,800,000₽/год
```

**ВАУ-эффект:** "Вы теряете 105,000₽/день! Это 3,150,000₽/мес! За год — 37,800,000₽!"

### 2.4 Структура HTML iframe

**HTML структура:**

```html
<div class="calculator">
  <h3>Калькулятор потерь</h3>

  <div class="input-group">
    <label>Средний чек (₽)</label>
    <input type="number" id="avgCheck" placeholder="3500">
  </div>

  <div class="input-group">
    <label>Заявок в день</label>
    <input type="number" id="leadsPerDay" placeholder="200">
  </div>

  <div class="input-group">
    <label>Обрабатываете (%)</label>
    <input type="number" id="processedPercent" placeholder="25" min="0" max="100">
  </div>

  <div class="results" id="results" style="display:none;">
    <h4>📊 ВАШИ ПОТЕРИ:</h4>
    <p class="warning">⚠️ Необработанные заявки: <span id="unprocessed"></span> заявок/день</p>
    <p class="loss-day">💸 Потери в день: <span id="lossDay"></span> ₽</p>
    <p class="loss-month">💸 Потери в месяц: <span id="lossMonth"></span> ₽</p>
    <p class="loss-year">💸 Потери в год: <span id="lossYear"></span> ₽</p>
  </div>
</div>

<script>
  // JavaScript для автоматического расчета
  const avgCheck = document.getElementById('avgCheck');
  const leadsPerDay = document.getElementById('leadsPerDay');
  const processedPercent = document.getElementById('processedPercent');
  const results = document.getElementById('results');

  function calculate() {
    const check = parseFloat(avgCheck.value) || 0;
    const leads = parseFloat(leadsPerDay.value) || 0;
    const processed = parseFloat(processedPercent.value) || 0;

    if (check > 0 && leads > 0 && processed >= 0) {
      const unprocessed = Math.round(leads * (100 - processed) / 100);
      const conversion = 0.20; // 20%
      const lossDay = Math.round(unprocessed * conversion * check);
      const lossMonth = lossDay * 30;
      const lossYear = lossMonth * 12;

      document.getElementById('unprocessed').textContent = unprocessed.toLocaleString('ru-RU');
      document.getElementById('lossDay').textContent = lossDay.toLocaleString('ru-RU');
      document.getElementById('lossMonth').textContent = lossMonth.toLocaleString('ru-RU');
      document.getElementById('lossYear').textContent = lossYear.toLocaleString('ru-RU');

      results.style.display = 'block';
    } else {
      results.style.display = 'none';
    }
  }

  avgCheck.addEventListener('input', calculate);
  leadsPerDay.addEventListener('input', calculate);
  processedPercent.addEventListener('input', calculate);
</script>
```
